## Project description（项目描述，600 字符内）
Built a retrieval-augmented generation (RAG) app that lets users upload PDFs, Word files and text documents and ask questions in plain language. Answers are grounded in the documents and cite the exact file and page, reducing hallucinations. Supports OpenAI GPT and Anthropic Claude, semantic search with embeddings or offline BM25 keyword search, and multi-turn chat. Streamlit UI, modular Python code, unit-tested.

## Skills and deliverables（技能标签）
